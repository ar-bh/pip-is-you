# Pip's Acorns
### by Arjun Bhumula

## Game
Pip's Acorns is a puzzle game inspired by **Baba is You** where you use similar mechanics from that game to help Pip the squirrel get to the acorn.
There are a total of 5 levels for you to play through

## Software used
* Godot
* Libresprite
* Github Desktop

## Controls:
* Arrow Keys or WASD to move in any 2D direction
* Z to undo a move
* R to restart a level
* click to navigate

## Features
* switch who YOU is
* move in all 4 directions (left, right, up, down)
* comic panels to tell a story
* my favorite large pixel art style
